Privacy policy

ECHOES: Time Loop Puzzle, by Brainrot Interactive Studios. Last updated 30 September 2026.

The short version

ECHOES does not collect, store, share or sell any personal information. There are no accounts, no ads, no analytics and no tracking of any kind, in the game or on this website.

What the game stores

The game saves a small file on your own device with your progress (which levels you have unlocked, your stars and your best number of loops) and your settings (touch controls, sound). This file never leaves your device. Uninstalling the game deletes it.

Network access

The game does not need an internet connection and does not send anything over the network. The Android package includes the standard network permissions of the game engine it is built with, but the game makes no network requests.

Permissions

The game asks for no special permissions: no location, camera, microphone, contacts, photos or files.

Children

Because no personal information is collected from anyone, none is collected from children.

This website

This site uses no cookies, no analytics and no third-party scripts or fonts. It is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) for security, as all web hosts do.

Changes and contact

If this ever changes, this page will be updated before the game is, and the date above will change. For questions, use the developer contact email shown on the game's Google Play page.
