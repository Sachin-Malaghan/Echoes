# ECHOES

*You are your only teammate.*

A 2D puzzle platformer where every level is a 10-second time loop. When time runs out, or you press
Rewind, your run replays as a glowing Echo while you play again. Echoes hold plates, keep doors open and
become the step you need. On the last loop, every Echo moves in sync and the level solves itself.

Unreal Engine 5.8 (C++), Android first, then iOS; Windows for development. Everything on screen is drawn
in code: no imported art.

- `CLAUDE.md`: the project spec (architecture, Echo rules, art direction, commands, milestones)
- `SETUP.md`: what to install to build it
- `Tools/SimHarness`: the game's core logic, tested in seconds without Unreal
